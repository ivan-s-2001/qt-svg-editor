# Guide frame transform

- Рамка рабочей области больше не рисуется HTML border-ом, который расширял div и съезжал относительно объекта.
- Рамка осталась внутри `foreignObject`, но теперь внутри него рисуется SVG `rect`.
- Для рамки используется тот же `viewBox` и `transform`, что и в `добавитьФигуру()`, поэтому она совпадает с итоговой областью path после вписывания обводки.
- В селекте оставлен один вариант `view_old` без дублирования `oldview`.
