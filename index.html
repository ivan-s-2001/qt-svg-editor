Загрузить объект

Импорт готовой фигуры в текущий редактор
Поддерживаются PHP и любой текст с объектом
PHP $g->добавитьФигуру([...]);
HTML <div generated_object><svg><path ...>
любой текст INSERT / UPDATE / комментарий с <div><svg><path>

После загрузки обновятся x/y/width/height, path, заливка, обводка и толщина обводки. Для HTML без координат x/y текущая позиция объекта сохраняется. Если текст является SQL INSERT/UPDATE place_obj, координаты и размеры по возможности берутся из колонок x/y/width/height; иначе используются размеры внешнего div или viewBox.
